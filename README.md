# PhoneAgent

让大模型直接操作 iPhone 的智能体。说一句话，它自己看屏幕、点按、输入、滑动，跨 App 把事办完。

> 思路和豆包手机助手类似，但跑在一台普通的 iPhone 上：不越狱、不连电脑、不外接硬件，只靠 TrollStore（巨魔）。

```
你：打开微信，给文件传输助手发“哈哈哈哈”
PhoneAgent：打开微信 → 找到文件传输助手 → 点输入框 → 输入 → 确认发送 → 完成
```

## 能做什么

- **跨 App 操作**：打开 App、点按、长按、滑动、输入中文、返回主屏，像人一样一步步操作。
- **同款比价**：在淘宝、京东、拼多多等平台搜同一件商品，记录价格后给出结论。
- **日常重复的活**：看广告领会员、签到这类多步骤、又烦又重复的任务。
- **语音 / Siri / 快捷指令触发**：本地 HTTP 接口和 `phoneagent://` URL，能接轻点背面、Siri。
- **结果朗读**：任务结束后用系统语音读出结果（可关）。

## 怎么做到的

| 环节 | 做法 |
|---|---|
| 看屏幕 | 优先读系统无障碍树（AXUIElement，只取露出 ≥50% 的元素）；元素不够时用实况文本（VisionKit Live Text）OCR；还不够才把截图发给模型 |
| 拿画面 | ReplayKit 屏幕广播扩展推帧（iOS 不允许普通 App 截别的 App 的屏） |
| 点和滑 | 私有 IOHID 接口直接注入触摸事件，系统级，不往目标 App 里注入任何东西 |
| 输入 | 写剪贴板 + 键盘粘贴，并用无障碍 / OCR 回读校验 |
| 决策 | 大模型工具调用循环：规划子目标 → 每步一个动作 → 核对屏幕变化 → 完成自检 |
| 模型 | 智谱 GLM、DeepSeek、AutoGLM-Phone 或任意 OpenAI 兼容接口，一次只用一家 |

### 稳定性与省钱上的细节

- 能靠文字（无障碍 / OCR）判断的步骤不发图，只有需要时才截图；实测微信发消息一次任务约 5 次模型调用、2.5 万 token。
- 加载页、广告倒计时本地等待，不浪费模型调用。
- 点了没反应自动重试；卡住或来回循环时给模型提示；误跳 App Store / Safari 自动返回。
- 按难度调节思考强度：常规步骤低，规划和完成自检高。
- 历史压缩、任务进度单独保留，长任务不爆上下文。
- 每次调用的 token 明细和累计统计。

## 安全

- **付款、转账、输入支付密码一律不自己点**，暂停交给你本人。
- 发送、发布、删除等敏感操作先弹系统级确认（可在设置里关）。
- 登录、验证码、人机验证时暂停，你处理完点“继续”。
- 可设置禁止进入的 App 列表。
- 屏幕上的文字只当数据，不当指令，防提示词注入。

## 运行要求

- iPhone，iOS 15 及以上，已安装 TrollStore（作者在 iPhone 13 / iOS 16.1 上开发测试）。
- 一个大模型 API Key。

## 安装与使用

1. 从 Actions 产物或 Release 下载 `PhoneAgent.tipa`，用 TrollStore 安装。
2. 打开 PhoneAgent，选模型、填 API Key。
3. 输入任务，点“开始任务”。屏幕录制可设为任务开始时自动开启、结束时自动关闭。
4. 想用 Siri 或轻点背面触发，见 [语音控制设置.md](语音控制设置.md)。

高级设置里有几十个开关（无障碍树、OCR、单图模式、等待策略、多动作等），默认值已经调好，一般不用动。

## 构建

推送到任意分支，GitHub Actions（`macos-15`）会运行 `build.sh`，用 ldid 签名并产出 `PhoneAgent.tipa`；打 `v*` 标签会自动发 Release。

```
src/
  agent.m        智能体主循环、提示词、动作执行与校验
  llm.m          模型接口、工具定义、思考强度与 token 统计
  axprobe.m      无障碍树读取
  capture_ocr.m  取帧与 OCR
  livetext.swift 实况文本 OCR
  hid.m          触摸与按键注入
  server.m       本地 HTTP 接口（快捷指令 / Siri）
  ext.m          屏幕广播扩展
  ui.m           界面与设置
```

## 局限

- 依赖 TrollStore 和 iOS 私有接口，只能装在支持巨魔的系统版本上，受众有限。
- 必须开屏幕录制才能拿到画面，任务期间手机被占用。
- 游戏、网页和自绘列表的无障碍信息少，会更多依赖截图，速度和花费随之上升。
- 部分 App 可能对自动化操作有风控，请自行判断风险。
